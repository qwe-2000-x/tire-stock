# 轮胎库存管理（网页版）

一个链接就能用的轮胎价格 + 库存系统：**谁点开都能搜规格看价格和库存，只有管理员能改库存和换价格表**。

---

## 一、现在能做什么

**谁都能用（不用登录）**

- 打开就是价格表，输入 `195` 就把所有规格里含 195 的轮胎列出来
- 每条显示：规格、花纹、系列、门店价格、京东价格
- 有库存的在右边显示 `12 条`；**没库存的就什么都不显示**，商品本身照常留在列表里
- 点进去看详情：只会显示"录过的"字段，没录的整行不出现（不会出现 0、空、null）

**管理员（口令登录）**

- 单条入库 / 出库（规格、花纹、数量、单价），数量自动累加，出库扣到 0 自动清掉
- **批量入库**：选一个表格文件 → 预览确认 → 入库
- **批量出库**：同样，点"出库"按钮就是出库
- **导入价格表**：换新价格表时，整份替换这一份价格表的数据，其他价格表不受影响
- **导出**：CSV 或 Excel（.xlsx），可以选"全部规格"或"只有库存的"
- 管理员权限移交：加人、删人，被删的人立刻失效

**文件格式**：`.xls`、`.xlsx`、`.csv` 三种都支持。

---

## 二、为什么是网页，不是小程序

| 对比项 | 微信小程序 | 网页（现在这套） |
| --- | --- | --- |
| 上线要审核吗 | 要，每次改版重新审 1~3 天 | **不用审核**，改完部署即生效 |
| 要备案吗 | 新注册的小程序必须完成工信部备案 | 用 Cloudflare 免费域名，**不用备案** |
| 要主体资质吗 | 个人主体类目受限 | 不需要 |
| 别人怎么用 | 搜名字、扫码 | **一个链接发群里，点开就能用** |
| 电脑上能用吗 | 不能 | 能，电脑上导 xls 更方便 |

小程序唯一更好的两件事，和替代方案：

1. **静默拿微信身份（openid）** —— 网页拿不到，改成了**管理口令登录**，同样是云端校验，伪造的令牌一律被拒。
2. **`wx.chooseMessageFile` 从聊天记录选文件** —— 网页调不了。改成了系统文件选择器，另外**每个导入区下面都有"直接粘贴表格内容"**：从微信里复制表格，粘进去就能导，这条在任何手机上都不会失败。

## 四、本地跑起来看看（5 分钟）

需要 Node 20 或更高版本。

```powershell
cd "E:\Codex working\tire-stock-web"
npm install
npx wrangler d1 execute tire-stock --local --file=./schema.sql   # 建表
npx wrangler d1 execute tire-stock --local --file=./seed.sql     # 灌入两份价格表
npx wrangler dev --local                                          # 起服务
```

浏览器打开 `http://127.0.0.1:8787`，搜 `195` 就能看到效果；右上角"管理"用 `.dev.vars` 里的口令 `dev-super-123456` 登录。

跑测试：

```powershell
npm test                                                          # 业务规则，42 项
node test/http-smoke.mjs http://127.0.0.1:8787 dev-super-123456    # 接口端到端，33 项
node test/ui-test.mjs    http://127.0.0.1:8787 dev-super-123456    # 页面，68 项
```

页面测试会真开一个无头浏览器，点按钮、选文件、粘贴表格，看页面变成什么样，专门兜住"看起来不对但接口是好的"这类毛病（需要本机有 Chrome 或 Edge，装在别处就设环境变量 `CHROME_PATH`）。

## 五、正式上线（Cloudflare，免费，大约 15 分钟）

免费额度：每天 10 万次请求、数据库 5GB，一个轮胎店用很久都够。

```powershell
npx wrangler login                       # 注册/登录 Cloudflare，点 Authorize
npx wrangler d1 create tire-stock        # 把打印出来的 database_id 填进 wrangler.toml
npx wrangler d1 execute tire-stock --remote --file=./schema.sql    # 建表
npx wrangler d1 execute tire-stock --remote --file=./seed.sql      # 灌入价格表
npx wrangler secret put SUPER_PASSWORD   # 设超级管理员口令，建议 12 位以上
npx wrangler secret put SESSION_SECRET   # 再设一个随机长串，用来签名登录令牌
npx wrangler deploy                      # 打印出来的网址就是发群里的链接
```

### 试用一遍

1. 打开网址 → 搜 `195` → 应该列出一堆规格和价格，都没有库存标记
2. 点右上角"管理" → 输口令 → 进后台
3. "单条入库"填 `195/60R15`、花纹 `ZTR50`、数量 `10` → 点入库
4. 返回首页搜 `195/60R15` → 那条右边出现 `10 条`
5. 回后台做一次出库，确认首页数字立刻跟着变

## 六、如果 `workers.dev` 在国内打不开

部署完请用**手机流量**（别用店里 WiFi）打开链接确认一次。打不开的话两条路，都不用备案：

**路 A：绑自己的域名（推荐）**
买个域名（阿里云/腾讯云，几十块一年），解析托管到 Cloudflare，然后在
`Workers & Pages → 你的 Worker → Settings → Domains & Routes → Add → Custom Domain` 绑上去。
链接变成 `https://stock.你的域名.com`，国内可访问性会好很多。

**路 B：换到自己的服务器**
买台香港轻量应用服务器（约 ¥30/月，免备案），把项目传上去：

```bash
node server/node-server.js
```

同一套业务代码，只是数据库换成服务器本地的 SQLite 文件（存在 `data/`）。开机自启、HTTPS 证书这些需要时我再给你脚本。

## 七、表格文件怎么写

### 出入库文件（批量入库 / 批量出库共用）

必须有的列：**规格**、**数量**。可选：**花纹**、**单价**。

| 规格 | 花纹 | 数量 | 单价 |
| --- | --- | --- | --- |
| 195/60R15 | ZTR50 | 10 | 88.5 |
| 195/65R15 | ACE i5 | 6 | 300 |

出库就是把同一个文件交给"批量出库"，不用在文件里写"出库"两个字。

### 价格表文件

必须有的列：**规格**（或叫"商品名称"）。价格列至少有一列（门店价格 或 京东价）。

| 商品名称 | 系列 | 花纹 | 门店价格 | 京东/天猫 |
| --- | --- | --- | --- | --- |
| 165/70R13 | ZETA | ZTR50 | 368 | 480 |

### 宽容度（都支持）

- 列的顺序随便排，多出来的列会被忽略
- 表头别名：`规格`/`型号`/`商品名称`/`规格&速级负荷`；`门店价格`/`给门店价格`/`门店价`；`京东价`/`京东/天猫`；`数量`/`库存`
- 表头前面有空格、带 BOM、大小写不同都能认
- `"高端, 舒适型"` 这种带逗号的内容用双引号包起来就不会被拆开
- 空行自动跳过；价格表表尾的署名、日期不会变成商品
- 制表符分隔（从 Excel 直接复制粘贴过来）也能认
- UTF-8 优先，读不出来自动按 GBK 再试一次

### 导入结果

先弹预览：解析到多少行、识别到哪些列、前 3 行长什么样，确认了才真正写库。
导入完弹结果：`成功 N 行，失败 M 行`，失败的逐条列出行号和原因，比如
`第 3 行：库存不足（当前 5 条）`、`第 5 行：数量必须是大于 0 的整数`。
某一行失败不影响其他行。

## 八、数据是怎么组织的

- **一条库存 = 规格 + 花纹**。同一规格不同花纹分开算（这是按你给的文件列来的，进出库文件里就是这两列）
- **价格表可以有多份**，导入时用"价格表名称"区分。同名再导一次就是整份替换，不会翻倍；不同名的互不影响
- **价格表名称只给管理员看**：前台的列表、详情页、导出的文件里都不会出现它
- **空字段不写库**：价格表里没填的列不会写 0，也不会在页面上显示成空行
- **出库扣到 0** 就删掉这条库存，商品还在价格表里，只是不显示库存数字
- **每笔出入库都记流水**，含数量和单价，后台"最近出入库"能看到最近 8 条，需要更长的对账表再加页面就行

现有两份价格表的名字是 **「安睿驰价格表」**（305 条）和 **「瑞途价格表」**（248 条）。
以后重新导入时，后台会把这几个名字做成按钮列出来，点一下就用这个名字，不会选错。
页面上还会明确提示：`会整份替换「安睿驰价格表」原来的 305 行，其他价格表不动。`
名字对不上时，它会提醒你这是新名字，会和现有的并存。

### 换新的价格表

1. 后台 → "导入价格表" → 选新文件
2. "价格表名称"点一下「安睿驰价格表」或「瑞途价格表」的按钮（选文件后也会自动填：文件名相近时会自动对上已有的名字）
3. 预览 → 确认导入

两份价格表分别是两个名字，换其中一份不会影响另一份。

## 十、常见问题

**问：忘了超级管理员口令？**
答：重设一次就行，旧的自动作废：`npx wrangler secret put SUPER_PASSWORD`，再 `npx wrangler deploy`。

**问：数据在哪？会丢吗？**
答：Cloudflare 的 D1 数据库里。想备份就点"导出"存到自己电脑。

**问：想只让管理员看到价格？**
答：现在价格对所有点开链接的人可见。要改成"只有管理员能看价格"，跟我说一声。

**问：微信里点"选择文件"没反应？**
答：用旁边的"直接粘贴表格内容"，从微信里复制表格粘进去，一样能导。

**问：微信里导出 xlsx 没反应？**
答：微信的浏览器对文件下载支持不稳定，导出选 CSV 更稳；CSV 导完页面上还会给一份可以长按复制的文本。

**问：导入价格表会不会把库存弄丢？**
答：不会。价格表和库存是分开存的，换价格表只影响价格。旧规格如果在新价格表里没有了，它的库存还会留着，只是暂时没有价格信息。

**问：想换标题、换颜色？**
答：标题在 `public/index.html`，颜色在 `public/styles.css` 顶部的 `:root` 里，改完 `npx wrangler deploy`。
